# Data folder

Download the PlantVillage dataset from Kaggle, pick the 3 crop folders
(e.g. Tomato, Potato, Maize/Corn), and split into:

- data/train/<class_name>/*.jpg
- data/val/<class_name>/*.jpg
- data/test/<class_name>/*.jpg  (include some real-world field photos here too)

Do not commit large image files to GitHub - keep this folder in .gitignore
except for this README.
